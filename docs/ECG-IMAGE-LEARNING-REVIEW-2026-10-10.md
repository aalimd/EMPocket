# مراجعة الدور التعليمي لصور ECG — 10 أكتوبر 2026

## الحكم التعليمي

كانت الصفحة أقرب إلى مرجع للأنماط: مفيدة لمن يعرف الموجات، لكنها لا تشرح للمبتدئ بوضوح ماذا يبحث عنه أولًا، وما الذي يجوز استنتاجه من كل صورة. أُضيف مدخل يبدأ بضربة طبيعية، ثم هدف لكل صورة، وقراءة مرتبة مرتبطة بمواضعها، وسؤال بإجابة مخفية. هذه مراجعة تعليمية وبصرية للتطبيق المحلي، وليست دراسة استخدام مع أطباء امتياز أو إثباتًا لاكتساب كفاءة سريرية.

## التغييرات

- مدخل يشرح P وQRS وT وJ وPR وST وTP، والفرق بين interval وsegment، قبل عرض الأنماط المرضية. الرسم مفاهيمي وغير مخصص للقياس.
- لكل صورة: هدف محدد، نقاط مشاهدة تفتح المنطقة الصحيحة في الشرح، وسؤال يتطلب التمييز بين المشاهدة والاستنتاج.
- في الجوال يبدأ العرض بمنطقة مقربة؛ يمكن استعادة الرسم كاملًا. الشرح يركز على المنطقة المختارة في التخطيطات المُعايرة البديلة، مع زر Whole ECG لاستعادة السياق.
- يذكر شرح المنطقة المقربة الاشتقاقات المعلّمة واسم الاشتقاق الأول المعروض، حتى إذا أصبح اسم الاشتقاق الأصلي خارج إطار التكبير. فُحص ذلك بصريًا في انخفاض PR وterminal R في aVR.
- التمييز بين ECG كامل، شريط مختار، مرجع نظم، أمثلة منفصلة، ورسم مفاهيمي. لا يُقدَّم lead II الطبيعي كمرجع مورفولوجي لنمط في V2/V3.
- توضيح أن صورة الخطوة السابعة تعرض احتمالات فرط البوتاسيوم فقط؛ بقية الأسباب لها بطاقات مستقلة.
- التحقق من الصورة النهائية بعد التحميل: يستبدل المنهج تسع رسومات بتخطيطات اصطناعية مُعايرة. عُدلت عبارات نقص البوتاسيوم وTCA لتطابقها، وأضيفت مقاطع مقربة لها. التخطيط المُعاير الاصطناعي لا يُقدَّم كتسجيل مريض موثّق.

## دور الصور الـ26 الظاهرة في الصفحة

| الصورة | العمل التعليمي المطلوب منها |
|---|---|
| الورق والمعايرة | تحويل المربعات إلى زمن وجهد، ثم حساب النبض مع مراعاة السرعة وانتظام النظم |
| ECG طبيعي كامل | ربط الضربة الطبيعية بتوزيع الاشتقاقات والنوافذ الزمنية وشريط II المستمر |
| النظم والمحور | فصل انتظام النظم وعرض QRS والمحور قبل تسمية التشخيص |
| الفترات | تحديد بدايات ونهايات PR وQRS وQT واستبعاد U المنفصلة |
| تضخم الحجرات والجهد | مراعاة gain والقياس peak-to-peak وعدم مساواة معيار الجهد بتشخيص التضخم |
| خريطة الإقفار | قياس J من baseline صالح وفهم اختلاف حدود V2/V3 والاشتقاقات المتجاورة |
| أنماط الإقفار عالية الخطورة | مقارنة hyperacute وde Winter وWellens بوصفها أمثلة منفصلة |
| صورة الخطوة السابعة | مقارنة ثلاثة احتمالات لفرط البوتاسيوم دون ترتيب حتمي أو تقدير تركيزه |
| STEMI | قراءة الاشتقاقات السفلية مع التغير المقابل في aVL |
| Hyperacute T | مقارنة T العريضة الضخمة بالطبيعية والمدببة في الاشتقاق نفسه |
| Wellens | التعرف على تغيرات T الأمامية في سياق الذبحة الحديثة وتجنب استنتاج انسداد حالي من الشكل وحده |
| de Winter | تتبع J المنخفض ثم ST الصاعد وT البارزة |
| Modified Sgarbossa | مقارنة اتجاه ST بـQRS وقياس التناسب في الاشتقاق نفسه |
| Posterior OMI | ربط التغير المرآتي الأمامي بالاشتقاقات الخلفية |
| aVR مع انخفاض ST واسع | التعرف على توزيع عالي الخطورة دون الجزم بآفة left main |
| Hyperkalemia | البحث عن تغيرات P وPR وQRS وT دون ربط الشكل بقيمة بوتاسيوم محددة |
| Hypokalemia | فصل T الصغيرة عن U اللاحقة عند قراءة QT |
| Hypothermia | تحديد J hump وعدم استخدامها لقياس الحرارة |
| Brugada | تتبع coved ST إلى T السالبة وفصل النمط عن تشخيص المتلازمة |
| PE strain | ربط S في I وQ/T في III وT الأمامية دون إثبات أو نفي PE بها |
| Pericarditis | مقارنة PR وST مع TP في II وaVR؛ البدائل المذكورة في النص ليست مرسومة كلها |
| TCA toxicity | تحديد terminal R في aVR وQRS العريض مع ضرورة سياق التعرض |
| WPW | تحديد PR القصير وdelta وعدم الخلط مع pre-excited AF |
| VT مقابل SVT | البحث عن استقلال الأذين وcapture/fusion دون اشتراط وجودها |
| Complete heart block | مقارنة ساعتي P–P وR–R وعدم افتراض توصيل P القريبة من QRS |
| Electrical alternans | مقارنة أحجام QRS المتعاقبة دون تشخيص tamponade من العلامة وحدها |

توجد أيضًا مادة AF داخل مكتبة العارض؛ أضيف لها هدف وسؤال، لكنها ليست من الصور الـ26 الظاهرة في الصفحة.
